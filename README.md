# anythingame

## 궤도 점프

`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다.

- 탭 / 스페이스: 다음 궤도로 점프
- 길게 누르기 / Shift / 방향키: 회전 방향 전환
- 별을 모으면 콤보 점수, 운석에 닿으면 게임 오버

## 작은 정원 (힐링 게임)

`garden.html`을 브라우저에서 열면 됩니다. 실패도 시간 제한도 없는 정원 가꾸기 게임입니다.

- 빈 땅을 누르면 씨앗을 심고, 식물을 누르면 물을 줍니다 (새싹 → 잎 → 꽃봉오리 → 꽃)
- 꽃을 만지면 낮에는 나비, 밤에는 반딧불이가 날아오릅니다
- 약 2분 30초마다 낮과 밤이 바뀌고, 가끔 보슬비가 내려 정원에 물을 줍니다
- 누를 때마다 오음계 차임이 울려요 (🔔 버튼으로 끄기)
- 정원은 브라우저에 자동 저장됩니다

## 다섯 나라의 섬 (3D 풍경 여행 · 소통 게임)

`island.html`을 브라우저에서 열면 됩니다 (인터넷 연결 없이도 동작, Three.js 포함).
교토 · 포르투갈 · 프랑스 · 아이슬란드 · 스위스가 하나로 합쳐진 섬을 걸어 다니며 명소를 발견하고, 현지 사람들과 이야기하며 부탁을 들어주는 게임입니다.

**명소 (19곳)** — 실제 생김새를 단순화해 재현
- 🇫🇷 에펠탑(격자 철골·밤 조명), 파리 오스만 건물, 이에나 다리, 몽생미셸(갯벌 위 바위섬 수도원), 프로방스 라벤더 밭
- 🇵🇹 벨렝탑, 리스본 언덕 집들과 노란 28번 트램, 4월 25일 다리, 페나 성
- 🇯🇵 금각사와 연못, 후시미 이나리 천본 도리이, 야사카 오층탑과 니넨자카 골목, 아라시야마 대나무 숲, 도게츠쿄
- 🇮🇸 할그림스키르캬, 스코가포스 폭포(무지개), 게이시르 간헐천, 블루라군, 검은 모래 해변과 주상절리, 밤의 오로라
- 🇨🇭 마터호른, 시옹성, 루체른 카펠교와 물탑, 샬레와 소

**조작**: WASD 걷기 · Shift 달리기 · Space 점프 · 마우스 드래그 시점 · 휠 줌 · E 대화/줍기 · M 지도(핀을 눌러 순간이동) · J 수첩 · T 시간 바꾸기 · F 패러글라이딩 · H 사진 모드. 모바일은 화면 왼쪽 드래그로 이동, 오른쪽 드래그로 시점.

**소통**: 나라마다 한 명씩 사는 친구(시그리드, 루카스, 클로에, 주앙, 하루카)와 대화하고, 다른 나라에서 물건을 구해다 주면 친구가 됩니다. 진행 상황은 브라우저에 저장됩니다.

코드 구성: `island/terrain.js`(지형·강·호수), `island/nature.js`(하늘·물·나무·오로라), `island/landmarks.js`(명소), `island/game.js`(플레이어·대화·UI).
느린 기기에서는 `island.html?lq`로 그림자를 끄고 해상도를 낮출 수 있습니다.
