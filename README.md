# anythingame

## 궤도 점프

`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다.

- 탭 / 스페이스: 다음 궤도로 점프
- 길게 누르기 / Shift / 방향키: 회전 방향 전환
- 별을 모으면 콤보 점수, 운석에 닿으면 게임 오버

## 작은 정원 (힐링 게임)

`garden.html`을 브라우저에서 열면 됩니다. 실패도 시간 제한도 없는 정원 가꾸기 게임입니다.

- 빈 땅을 누르면 씨앗을 심고, 식물을 누르면 물을 줍니다 (새싹 → 잎 → 꽃봉오리 → 꽃)
- 꽃을 만지면 낮에는 나비, 밤에는 반딧불이가 날아오릅니다
- 약 2분 30초마다 낮과 밤이 바뀌고, 가끔 보슬비가 내려 정원에 물을 줍니다
- 누를 때마다 오음계 차임이 울려요 (🔔 버튼으로 끄기)
- 정원은 브라우저에 자동 저장됩니다
